## Overview

A GovStack Specification is a document that identifies the requirements a conformant implementation must satisfy. 

It provides together with the terminology, data structures, interfaces and verification information needed to build and test such an implementation. 

It inherits from the Software Requirements Specification (SRS): described in ISO/IEC/IEEE 29148:2018.

It is applicable to all GovStack Specifications that contain GovStack Requirements. 

This document describes the outline of such a document.
